# Security policy

Please do not report secrets, API keys, private factory data, or exploit details in a public issue. Use a private security report through the repository’s GitHub security advisory workflow when it is enabled.

The agent is designed for read-only analysis of approved datasets. Gemini may propose plans and code, but the host validates plans, generated code, sandbox results, and output files. Do not treat the sandbox as independently audited production isolation.

Supported versions: the latest `main` branch and the latest tagged release.
